# CardioScan — Heart Disease Risk Estimator

A Streamlit app that estimates heart disease risk from clinical intake values, built on top of the model trained in `heart_disease.ipynb` (UCI Heart Disease dataset).

![status](https://img.shields.io/badge/status-demo-blue) ![python](https://img.shields.io/badge/python-3.9%2B-blue)

## What it does

You fill in a patient's demographics, vitals, and cardiac test results. The app rebuilds the exact feature vector the model was trained on, scales it, and returns:

- A predicted probability of heart disease
- A Low / Moderate / High risk badge
- The model's top global signals (feature importances)

> This is a machine learning demo, not a diagnostic device. It does not replace clinical judgment.

## Project structure


## Setup

**1. Clone / download this project**, and make sure these five files are together in one folder:
`app.py`, `requirements.txt`, `heart_disease.ipynb`, `heart_disease_uci.csv`, and (after step 3) the two `.pkl` files.

**2. Create a virtual environment (recommended)**

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

**3. Generate the model files**

If you don't already have `heart_disease_model.pkl` and `heart_disease_scaler.pkl`, run `heart_disease.ipynb` end to end (through the `joblib.dump(...)` cell). This trains the model on `heart_disease_uci.csv` and saves both files into the project folder.

> Get the dataset from the [UCI Heart Disease dataset on Kaggle](https://www.kaggle.com/datasets/redwankarimsony/heart-disease-data) if you don't have `heart_disease_uci.csv` locally — save it into this folder before running the notebook.

**4. Run the app**

```bash
streamlit run app.py
```

It opens at `http://localhost:8501`.

## Deploying (Streamlit Community Cloud)

1. Push this folder to a GitHub repo, **including** `heart_disease_model.pkl` and `heart_disease_scaler.pkl` (or regenerate them in a build step).
2. Go to [share.streamlit.io](https://share.streamlit.io), connect the repo, and set the main file path to `app.py`.
3. Deploy — Streamlit Cloud installs `requirements.txt` automatically.

## Model details

- **Algorithm:** Gradient Boosting Classifier (best-performing of six models compared in the notebook: Logistic Regression, Decision Tree, Random Forest, KNN, SVM, Gradient Boosting)
- **Test accuracy:** ~85.9%
- **Test F1 score:** ~0.877
- **Features:** 21, after one-hot encoding age, sex, chest pain type, resting BP, cholesterol, fasting blood sugar, resting ECG, max heart rate, exercise-induced angina, ST depression, ST slope, number of major vessels, thalassemia, and study site

## Notes & caveats

- The **study site** field (Cleveland / Hungary / Switzerland / VA Long Beach) is included only because the model was trained on pooled multi-site data — it isn't a real clinical risk factor and shouldn't be read as one.
- Risk thresholds (Low < 30%, Moderate 30–60%, High > 60%) are illustrative cutoffs for this demo, not clinical guidelines.
- No cross-validation or hyperparameter tuning was applied to the saved model — see the notebook's discussion cells for planned improvements.
